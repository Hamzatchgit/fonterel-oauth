# fonterel-oauth

Page statique de retour OAuth (callback) **provisoire** pour l'application AliExpress Open Platform du projet Fonterel.
Elle affiche le paramètre `code` reçu dans l'adresse et propose de le copier. Elle ne contient **aucun secret**, ne stocke rien et n'appelle aucun service.
Elle sera remplacée par une page du domaine Fonterel.
